# ISP Customer Analysis — Excel PivotTables

## Overview
This project demonstrates the use of Microsoft Excel for the web to analyse a small, fictional Internet Service Provider (ISP) customer dataset.

The project focuses on business questions involving customer status, subscription plans, monthly bill values, and acquisition channels.

## Research and business questions
1. How do Active and Cancelled customer counts differ across regions?
2. Which subscription plan has the highest total monthly bill value?
3. Which acquisition channel has the highest average monthly bill?

## Methods
- Data organisation and validation
- PivotTables using counts, sums, and averages
- PivotCharts for comparing categories
- Written findings, interpretations, and limitations

## Workbook contents
- `Day5_Data`: ISP practice dataset
- `Pivot_Analysis` or the equivalent analysis worksheet: PivotTables, charts, and interpretations

## Important data note
The dataset is fictional and intended for learning. It does not represent actual customer records or the financial performance of a real ISP. Findings must not be interpreted as evidence about the Bangladesh ISP market.

## Skills demonstrated
Microsoft Excel for the web, PivotTables, PivotCharts, descriptive analysis, data interpretation, and analytical documentation.

## Reproducibility
The workbook contains the source practice data and the calculations used to answer the stated questions. Readers can inspect the PivotTable field arrangements and compare the results with the source records.
